COMPLEXITY ANALYSIS
===================

1. TREE CONSTRUCTION

The organizational hierarchy is represented using a general tree.

Time Complexity: O(n)
Space Complexity: O(n)


2. LEVEL-ORDER TRAVERSAL

Level-order traversal visits every node in the tree once.

Time Complexity: O(n)
Space Complexity: O(n)

Tree Height: 3 edges (4 levels)


3. LINEAR SEARCH

Linear Search checks each department sequentially until the
required department is found.

Best Case: O(1)
Average Case: O(n)
Worst Case: O(n)
Space Complexity: O(1)


4. BINARY SEARCH

Binary Search works on the sorted department array and reduces
the search space by approximately half at each step.

Best Case: O(1)
Average Case: O(log n)
Worst Case: O(log n)
Space Complexity: O(1)


5. OVERALL COMPLEXITY TABLE

Operation                  Time Complexity    Space Complexity
--------------------------------------------------------------
Tree Construction          O(n)               O(n)
Level-order Traversal      O(n)               O(n)
Linear Search              O(n)               O(1)
Binary Search              O(log n)           O(1)


6. ANALYSIS

The general tree is suitable for representing the organizational
hierarchy because it clearly represents parent-child relationships.

Level-order traversal is suitable for organizational reporting
because it displays the hierarchy level by level.

For department searching, Binary Search is more efficient than
Linear Search when the department names are stored in sorted order.

Therefore, the combination of a general tree for organizational
representation and a sorted array with Binary Search for department
searching is suitable for this application.
